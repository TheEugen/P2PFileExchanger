# P2PFileExchanger

## Overview
P2PFileExchanger is a peer-to-peer (P2P) file exchange application written in C++. It allows users to share files directly between computers without relying on a centralized server, ensuring efficient and decentralized file transfers.

## Features
- **Peer-to-Peer Communication**: Direct file transfer between clients.
- **Client-Server Architecture**: Handles connections between multiple clients efficiently.
- **File IO Operations**: Manages file read/write operations securely.
- **Cross-Platform Support**: Designed to work on multiple operating systems.

## How to Run
1. Compile the source files using a C++ compiler.
2. Run the server to listen for incoming connections.
3. Run the client to connect to the server and start exchanging files.
